## Part I — Design constitution (applies to every phase)

Before any feature: the rules that separate a professional platform from a feature pile. They come from collapsing SAS's 76 observed defects into seven habits, inverted into laws — and our own live testing showed we already break several of them. **Enforce in code review; each gets a lint/test where possible.**

1. **No silent refusal.** Every refusal states a reason; every disabled or empty control says *which* cause applies (`not_saved`, `no_permission`, `no_dataset`, `no_column_of_this_type`, `no_selection`) and links the fix. **[TESTED — we break this today: an empty role dropdown on a report with no dataset explains nothing.]**
2. **No silent substitution.** Never change what the user asked for without naming the change on the object itself.
3. **No aggregation without semantics.** The semantic-type veto becomes *enforced*: latitude/year/ID columns can never be summed, never enter suggestion measure pools. Warn before summing any non-additive column.
4. **Truncation is a first-class state.** Every query result carries `rows_scanned`, `rows_returned`, `truncation{applied, limit, total, reason}`; every widget that drops rows says so in one shared vocabulary, with a one-click alternative.
5. **One disclosure vocabulary.** The same fact (caps, ranges, populations) is disclosed the same way on every surface — and empty states are never stale. **[TESTED — we break this today: "Attach a dataset to browse columns" stays on screen after the dataset is attached.]**
6. **Accessible by construction.** Every visual has a real DOM/ARIA equivalent generated from the same data the renderer draws.
7. **Assistive output is reproducible and explainable** — or it doesn't ship. (We already meet this bar — the Suggest pane labels its evidence; keep it as a gate.)
8. **Every mutation is one undo command** with one sentence grammar: *verb, item, role, object, new value*. **[TESTED — Ctrl+Z does nothing in the builder today.]**
9. **Never destroy configuration to change a mode.** Mode switches are additive and reversible.
10. **One naming function** produces widget title, accessible name, tooltip labels and undo label. **[TESTED — we break this today: a bar's tooltip reads `value : 514`, an internal key.]**

**Logic.** Wire- and convention-level changes that every later feature depends on (model objects need population headers; undo needs naming; suggestions need the veto; the Phase 1–2 UX work needs the reason-code pattern to render "why is this empty" everywhere). Retrofitting after the UI phases would mean touching every shaper and picker twice.

**Feature detail**
- Extend the widget-data response: `rows_scanned`, `rows_returned`, `truncation: {...}` on every shaper. Frontend: one shared `<PopulationBadge>` in every widget frame — prominent, not a tiny ⓘ.
- Standard refusal envelope `{code, reason, remedy?}`; shared frontend components: `disabledReason` tooltip on buttons/menu items, `EmptyState(reason, fixAction)` for pickers and panes.
- Semantic-type → aggregation policy table (latitude/longitude/year/identifier/code: sum **refused**; percentage: average default, sum refused; age/score/ratio: warn). Applied in `_agg_series`, measure validation, suggestion pools, and the drop resolver.
- `nameFor(widget|role|measure)` used by titles, tooltips (fixes `value : 514`), ARIA and, in Phase 1, undo sentences.

**Done when:** a bar over 1.7M groups says "Showing 3,000 of 1,712,442 — rank top N instead?"; summing a latitude is impossible; every grey button and empty picker explains itself; no tooltip ever shows an internal key.

- **Placeholder-first:** every widget type declares sample data; an unconfigured widget draws it dimmed (~40%) behind an **"Assign data"** button that opens the config panel directly on **Data roles** (not on Title/RTL). When required roles are unfilled, the panel always opens on Data roles with required roles marked `*`.
- **Recovery:** debounced (~750 ms) JSON-patch autosave of unsaved builder state to a per-user draft; "Restore previous session?" card on next open.

**Done when:** delete a widget, Ctrl+Z restores it with its sentence shown; a new widget is never a blank frame; killing the tab mid-edit loses nothing.
